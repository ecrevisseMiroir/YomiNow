# Contributing to YomiNow

Thank you for your interest in contributing! YomiNow is a Flutter app for Japanese OCR and dictionary lookup. It will be released as a **freemium** app in the future — contributions to the core open-source codebase are welcome, but please note that premium features may be developed separately.

## How to contribute

1. Fork the repository and create a feature branch.
2. Make your changes and ensure `flutter analyze` passes.
3. Add or update tests where appropriate (`flutter test`).
4. Open a pull request with a clear description.

See the [README.md](README.md) for setup instructions for Linux, Android, and iOS.
